## Overview

Pokemon encyclopedia pulling live creature metrics from PokeAPI with holographic 3D card tilt, stat radars, and instant type filtering.

## Key Features

- **Holographic cards:** Responsive 3D tilt reacting to cursor and touch gestures.
- **PokeAPI integration:** Real-time metrics for HP, Attack, Defense, Speed, and Special stats.
- **Type filtering:** Instant multi-type badge filters for Fire, Water, Grass, Electric, Psychic, and Dragon.
- **Search and evolution:** Instant name search and evolutionary progression chains.
- **Client caching:** Zero-latency memory caching for fluid infinite scrolling.

---

## Spatial Web and Mobile Viewport Specifications

- **Precision Viewport Scaling:** Mobile-first 2-column grid (360px-430px) expanding into a 4-column display on larger screens.
- **Touch Ergonomics:** Standard 48px minimum interactive tap boundaries across all buttons and inputs.
- **Performance Optimized:** Fast rendering, zero layout shifts, and responsive image loading.
- **Safe Area Inset Handling:** Dynamic insets accommodating modern mobile displays.

## Getting Started Locally

### Prerequisites
- Node.js (v18.0.0 or higher)
- Git installed on your system

### Installation and Run

```bash
git clone https://github.com/M20A03/Pokedex-Lite.git
cd Pokedex-Lite
npm install
npm run dev
```
