## 📖 Overview

Futuristic glassmorphic Pokémon encyclopedia pulling live creature metrics from PokeAPI with holographic 3D card tilt, stat radars, and instant type filtering.

## ✨ Key Features

- **Interactive holographic cards that react with 3D tilt to cursor/touch gestures**
- **Live PokéAPI integration displaying HP, Attack, Defense, Speed, and Special stats**
- **Instant multi-type badge filters (Fire, Water, Grass, Electric, Psychic, Dragon)**
- **Instant name search and evolutionary progression chain visualization**
- **Zero-latency client-side caching with smooth infinite scrolling**

## 💻 Getting Started Locally

### Prerequisites
- Node.js (v18.0.0 or higher) / Python 3.10+ (where applicable)
- Git installed on your system

### Installation & Run

```bash
git clone https://github.com/M20A03/Pokedex-Lite.git
cd Pokedex-Lite
npm install
npm start
```
